# Agent Quick Start — Images

These images accompany the **Agent — Quick Start** documentation (source: `Openterface_KeyCmd_Android/docs/Agent-Quick-Start.md`). They illustrate the step-by-step setup and usage of the Agent feature in the Openterface Android app.

## Image index

### 1. AI Provider configuration

| File | Description |
|---|---|
| `01-connect-ai-gate.png` | The "Connect AI" gate screen shown when AI is not yet configured, with the "Use my API key" button |
| `02-enable-ai-features.png` | The toggle/screen to enable AI features (disabled by default) |
| `03-ai-provider-setting.png` | AI Provider Setting screen — dropdown to open provider selection |
| `04-select-ai-provider.png` | Select AI Provider list (OpenAI, Anthropic, Google, DeepSeek, etc.) |
| `05-add-new-provider.png` | The green "Add New Provider" button for adding a custom provider |
| `06-confirm-add-provider.png` | Confirmation popup after tapping "Add New Provider" |
| `07-provider-basic-info.png` | Form to fill in provider name, API Base URL, and Model Name |
| `08-api-key-optional.png` | "API Key Optional" toggle setting for providers that don't require a key (e.g. local) |
| `09-update-api-key.png` | API Key Management section with the "Update API Key" button |
| `10-save-api-key.png` | Input field to paste the API Key, with the "Save key" button |
| `11-test-connection.png` | The "Test connection" button to verify AI configuration |
| `12-test-success.png` | Green notification shown when the connection test succeeds |
